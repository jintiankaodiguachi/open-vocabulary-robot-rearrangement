# Demo preparation

真机视频已录制，正在剪辑。仓库当前没有视频或截图，因此 README 不引用尚不存在的媒体。

建议选择一个完整任务，如 `blue stapler → cardboard box` 或 `banana → glass bowl`，保留正常速度的关键抓取片段，总长约 60–90 秒：

| Segment | What to show |
|---|---|
| 0–8 s | 两个文本查询、桌面物体与初始 HOME |
| 8–20 s | 全局 RGB、目标分割、机械臂主动观察 |
| 20–40 s | 局部感知、pregrasp、接近、闭合夹爪与抬升 |
| 40–65 s | 目标容器定位、放置、松开与退出 |
| 65–90 s | 返回 HOME、最终桌面结果；可补物体重新摆放后的任务 |

若加速等待过程，用字幕明确标明倍率；不要用剪辑隐去会影响理解的人工干预、失败或重试。演示画面可同时显示机器人和现有控制台，但 Web UI 源码尚待补充。

完整视频可发布到自己的 Bilibili 或其他视频账号，再把公开链接加入 README。这里不自动上传视频或向外部账号发布内容。精选 GIF/WebP 可放在 `docs/images/`，建议控制在数 MB；原始 MP4 已被 `.gitignore` 排除。

视频可用后，将 README 的 Demo 状态改为真实链接并加入实际截图。没有统计数据时，不添加成功率、实时性能或耗时指标。
